# B8A1: Problem Solving with TypeScript & OOP

This repository contains the solutions and technical blog posts for **Module 4: Assignment 1**, focusing on core TypeScript concepts and Object-Oriented Programming (OOP).

## 📋 Assignment Overview

The goal of this assignment is to demonstrate practical proficiency in TypeScript fundamentals, including:
- Basic types, union types, and readonly tuples
- Optional, default, and rest parameters
- Interfaces and `keyof` constraints
- Type narrowing (`typeof`)
- Generics and asynchronous operations (`Promise<T>`)
- Object-Oriented Programming (`class`, inheritance, `protected` and `private` access modifiers)
